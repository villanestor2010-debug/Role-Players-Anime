# Role-Players-Anime
Rôle players Anime est un site qui permet de vous épanouir dans le monde du RP, tant qu'en incarnant un personnage et de l'utiliser pour vous battre et gagner en expérience ! Quelle Technique adopter dans un combat, quelle stratégie utiliser, quelle combo a faire ! qu'en crée un et évoluer dans un monde "La quête du Sama" ! évolué dans ce monde avec votre race et clan de départ et monté des niveau et faîte augmenter vos stats, gagner des combat dans l'arène, réussissez vos mission dans des donjon avec brio, affronter les Sama ou Le grand Sama si vous avez du cran
